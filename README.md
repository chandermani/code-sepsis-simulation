# Code Sepsis – Urosepsis Simulation

A branching urosepsis simulation for medical students: 8 decisions, an animated patient who responds to your choices, and a debrief at the end.

**Play:** https://chandermani.github.io/code-sepsis-simulation/

**Install on iPad/iPhone:** open the link in Safari → Share → Add to Home Screen. It opens full screen and works offline.

For education only. Based on UK practice (NEWS2, Sepsis Six, NICE NG51). Follow local trust guidelines for doses and antibiotic choice.
